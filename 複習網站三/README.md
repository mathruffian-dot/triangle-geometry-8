## 開啟方式
直接用瀏覽器打開 `index.html`（需連網以載入 MathJax）。按「開始複習」進入；深連結：
- `index.html#present` → 直接進入簡報第一頁
- `index.html#p=20` → 直接跳到索引 20 的投影片（0 起算）

> ⚠️ 本機測試請用簡單伺服器：`python -m http.server 8883 --directory 複習網站三`。

清除筆跡（C）、全螢幕。Esc 關閉雷射筆／畫筆；畫筆支援觸控螢幕。

方便投影時用畫筆直接講解；按「✕ 關閉」回到原頁。

### 課綱邊界（本冊刻意不放）
- 多項式除法限**被除式最高為二次**（二次÷一次），**不涉及分離係數法**；直式乘法乘積最高至三次
- 因式限**二次多項式的一次因式**，**不做 x⁴−1 這類高次連續分解**；
  方法只有提公因式、乘法公式、十字交乘，**分組分解非課綱方法**
- 十字交乘只處理**整係數 ax²+bx+c**，**不出 x²+5xy+6y²** 這類二元齊次式
- 乘法公式只列四式；**三項式平方 (a+b+c)² 為補充**
- 一元二次方程式可判斷「根號內為正／零／負」，但**不用「判別式 D」的名稱與符號**，
  也**不做由判別式反推 k 的範圍**（高中內容，會考不考）
- 統計**不使用「百分位數」一詞**、**不混入平均數／中位數／眾數**（屬第 2 冊 5-2）
- 數列與級數（N-8-3～N-8-6）、一次函數（F-8-1、F-8-2）屬第 4 冊，本冊不出現
- 二次函數與拋物線屬第 6 冊，第 4 章刻意不延伸
