# 國中數學 八下（第 4 冊）全冊複習｜互動視覺化簡報

一頁一重點的簡報式複習網站，涵蓋 108 課綱國中數學八下（第 4 冊）全部四章，
每個重點都有**視覺化演示**與**範例**。規格與第一～五冊一致（見專案根目錄 `README.md`）。

## 開啟方式
直接用瀏覽器打開 `index.html` 即可（需連網以載入 MathJax 數學排版）。
按「開始複習」進入；也可用網址深連結：
- `index.html#present` → 直接進入簡報第一頁
- `index.html#p=20` → 直接跳到第 20 張投影片

> ⚠️ 用 `file://` 直接開，部分預覽環境會當成靜態快照而不執行 JS；
> 本機測試請用簡單伺服器：`python -m http.server 8787 --directory 複習網站`，再開 `http://localhost:8787`。

## 操作
- **← →** 或 **空白鍵**：上一頁 / 下一頁；**Home / End**：最前 / 最後
- 左側**目錄**可依章節快速跳頁；右上「☰ 目錄」在手機版可收合
- **33 頁有滑桿互動**：等差／等比數列產生器、高斯配對、函數描點作圖、平行截角，
  以及幾何性質／判別頁的**步驟滑桿**（全等判別 SSS/SAS/ASA/RHS、中垂線・角平分線・等腰三角形、
  畢氏逆定理、同位角／內錯角／同側內角／平行判別、平行四邊形性質與判別、
  矩形／菱形／正方形／箏形／等腰梯形／梯形中線）；部分步驟內可連續拖動，數值即時更新
- 範例可按「顯示解答」自我檢測

## 授課教具（右側浮動工具列）
收合側欄、上／下一頁、**雷射筆（L，含淡出拖尾）**、**畫筆（P，5 色＋橡皮擦）**、
清除筆跡（C）、全螢幕。Esc 關閉雷射筆／畫筆；畫筆支援觸控螢幕。

**🔍 放大**：範例框與視覺欄右上角各有一顆「放大」鈕，可把範例或圖解**放大成整頁**，
方便投影時用畫筆直接在上面講解；按「✕ 關閉」回到原頁（筆跡自動清除）。

## 一頁一螢幕
概念欄與視覺欄內容過高時會**自動等比縮小**，確保投影時整頁不需捲動。

## 檔案結構
- `index.html`：頁面骨架（封面、目錄、舞台、控制列、教具）
- `style.css`：全部樣式（與第一～五冊共用同一份）
- `svg.js`：共用 SVG 幾何工具（角弧、刻度、坐標平面、公式卡 fbox、步驟器 stepper…）
- `engine.js`：投影片導覽與渲染引擎（與第一～五冊共用同一份）
- `ch1.js ~ ch4.js`：各章投影片資料與視覺化（可獨立增修）

要新增 / 修改某一頁，只要編輯對應的 `chN.js` 內該投影片物件即可。
