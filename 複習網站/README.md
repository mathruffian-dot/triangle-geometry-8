# 國中數學 2下 全冊複習｜互動視覺化簡報

一頁一重點的簡報式複習網站，涵蓋 114 課綱國中數學二下（第 4 冊）全部四章，
每個重點都有**視覺化演示**與**範例**。

## 線上網址（可發給學生）
**https://math809-review.netlify.app**（Netlify 站台 math809-review，ID 3f28584a-030d-4f9f-8ef7-bea8c71e9235，2026-07-15 部署）

改版後重新部署（在專案根目錄執行，務必帶 --site 指定站台，因為根目錄 link 的是 math809-quiz）：
```
netlify deploy --dir "複習網站" --prod --site 3f28584a-030d-4f9f-8ef7-bea8c71e9235
```

## 開啟方式
直接用瀏覽器打開 `index.html` 即可（需連網以載入 MathJax 數學排版）。
按「開始複習」進入；也可用網址深連結：
- `index.html#present` → 直接進入簡報第一頁
- `index.html#p=20` → 直接跳到第 20 張投影片

## 操作
- **← →** 或 **空白鍵**：上一頁 / 下一頁
- **Home / End**：跳到最前 / 最後
- 左側**目錄**可依章節快速跳頁；右上「☰ 目錄」在手機版可收合
- 部分頁面有**滑桿 / 按鈕**互動（等差、等比數列產生器、高斯配對、函數繪圖、平行截角）
- **幾何性質／判別頁（21 頁）有「步驟滑桿」**：拖動滑桿逐步展開推理（全等判別 SSS/SAS/ASA/RHS、
  中垂線・角平分線・等腰三角形、畢氏逆定理、同位角／內錯角／同側內角／平行判別、
  平行四邊形性質與判別、矩形／菱形／正方形／箏形／等腰梯形／梯形中線）；
  部分步驟內可連續拖動（移動 P 點、轉動截線、扶正矩形、改變上底），數值即時更新
- 範例可按「顯示解答」自我檢測

## 授課教具（右側浮動工具列）
投影上課用，工具列由上到下：
- **收合側欄**：隱藏左側目錄，投影頁面變滿版（再按一次展開）
- **上一頁 / 下一頁**
- **雷射筆**：滑鼠變紅色光點，圈重點用（快捷鍵 **L**）
- **畫筆**：在畫面上手寫畫記，展開 5 色 + 橡皮擦（快捷鍵 **P**）
- **清除筆跡**（快捷鍵 **C**；換頁也會自動清除）
- **全螢幕**

> 快捷鍵：**Esc** 關閉雷射筆／畫筆。畫筆支援觸控螢幕。

## 內容範圍
| 章 | 節 |
|----|----|
| 第 1 章 數列與級數 | 1-1 等差數列、1-2 等差級數、1-3 等比數列 |
| 第 2 章 函數 | 2-1 函數與函數圖形 |
| 第 3 章 三角形的基本性質 | 3-1 內外角、3-2 尺規作圖、3-3 全等、3-4 中垂線與角平分線、3-5 邊角關係 |
| 第 4 章 平行與四邊形 | 4-1 平行、4-2 平行四邊形、4-3 特殊四邊形 |

共 4 張章名頁 + 63 張重點頁。滑桿等互動控制在寬螢幕會浮動於展示區右下角（手機版仍置於下方）。

> 內容遵循 108 課綱國中限制：函數不使用 f(x) 記號（F-8-1）、不出現斜率／截距術語（高中內容）；
> 尺規作圖含六大基本作圖（等線段、等角、中垂線、角平分線、過線上／線外一點作垂線），平行線作圖在 4-1。

## 檔案結構
- `index.html`：頁面骨架（封面、目錄、舞台、控制列）
- `style.css`：全部樣式
- `svg.js`：共用 SVG 幾何工具（角弧、刻度、坐標平面…）
- `engine.js`：投影片導覽與渲染引擎
- `ch1.js ~ ch4.js`：各章投影片資料與視覺化（可獨立增修）

要新增 / 修改某一頁，只要編輯對應的 `chN.js` 內該投影片物件即可。
