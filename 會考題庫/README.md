# 國中教育會考數學歷屆試題題庫（103–115 年）

共 **358 題**（選擇題 332 + 非選擇題 26），每題均比對 **108 課綱**學習內容／學習表現代碼，
標記冊別（B1–B6）與章節，附官方答案、詳解、逐步解題引導與易錯提醒。

## 使用方式

兩種開法（皆離線可用）：

| 檔案 | 適用情境 |
|---|---|
| **`index.html`** | 在本資料夾內開啟（需與 `01_題目圖片/` 同資料夾），檔案小、開啟快 |
| **`會考題庫單檔版.html`** | 圖片已內嵌的**單一檔案**（12.5MB），可單獨複製到隨身碟、其他電腦或傳給同事，不需要任何資料夾 |

功能：

- **篩選**：年度／冊別／章節／學習內容代碼／難度／題型／關鍵字
- **逐步引導**：每按一次「💡 逐步引導」多顯示一步，適合課堂引導
- **完整詳解**：答案＋解析＋「⚠ 易錯提醒」
- **出卷**：逐題勾選「選入試卷」→「🖨 列印勾選題目」出題目卷、「列印勾選（含詳解）」出教師卷
- **命題分析統計**：各冊別／章節／代碼的歷屆出題數分布


## 線上試卷（無後端）

1. 題庫中篩選（支援「最近N屆＋題號範圍」，如最近5屆第1-10題）→ 勾選 → 「🌐 匯出線上試卷」
2. 檔案改名 `index.html` 放入資料夾 → 拖進 [app.netlify.com/drop](https://app.netlify.com/drop) → 網址發給學生
   （已登入 Netlify CLI 也可：`netlify deploy --dir 資料夾 --prod`）
3. 學生 iPad 填班級/座號/姓名作答 → 交卷自動批改選擇題 → 產生**作答紀錄**（複製/分享/下載三種方式收回）
4. `netlify_deploy/` 內附示範卷（最近5屆第1-10題，50題）可直接部署測試

### 作答紀錄格式（預留後端接口）

紀錄為 JSON（學生端顯示為 base64，解碼即得）：

```json
{"v":1, "quiz":"卷名", "cls":"309", "seat":"12", "name":"王小明",
 "ts_start":"…", "ts_submit":"…", "dur_s":1234,
 "score":8, "total_auto":10,
 "answers":[{"id":"115-01","a":"C","ok":true}, …]}
```

之後要接後端：在試卷檔的 `CONFIG.submitUrl` 填入端點網址（POST JSON），
交卷時會自動上傳，其餘程式不需更動。`answers[].id` 可對回題庫的課綱標記，
做為後續「客製化補強生成」的資料來源。

## 維護

- 每年新試題公布後：`python scripts/download_exams.py`（改年份範圍）→ `crop_questions.py`
  → 手動撰寫 `data/questions_{年}.json` → `python scripts/build_html.py`
- 資料改動後：`python scripts/validate.py` 驗證、`python scripts/build_html.py` 重建網頁
