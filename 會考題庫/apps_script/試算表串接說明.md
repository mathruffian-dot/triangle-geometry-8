# 試算表收卷 — 一次性設定（約 5 分鐘）

做完這一次，之後學生交卷就自動寫進你的 Google 試算表，錯題分析可一鍵載入。

## 步驟

1. 開 <https://script.google.com> → 「新增專案」
2. 把同資料夾 **Code.gs** 的內容全部貼上（取代原本內容），Ctrl+S 存檔
3. 右上「**部署**」→「新增部署作業」→ 類型選「**網頁應用程式**」
   - 執行身分：**我**
   - 誰可以存取：**任何人**
   - 按「部署」→ 過程會要求授權（選你的帳號 → 進階 → 前往專案 → 允許）
4. 複製「網頁應用程式 URL」（長得像 `https://script.google.com/macros/s/AKfycb.../exec`）
5. 在網址後面加上 `?token=math809`，用瀏覽器開一次：
   `https://script.google.com/macros/s/…/exec?token=math809&setup=1`
   → 會回覆「試算表已就緒：<試算表網址>」（試算表自動建立，含「作答紀錄」「逐題明細」兩張表）
6. 到題庫（math809-bank.netlify.app）→「錯題分析」頁籤 → 最上方「試算表收卷設定」
   貼上：`https://script.google.com/macros/s/…/exec?token=math809` → 按「儲存」

## 完成後的效果

- **匯出線上試卷**時自動內嵌收卷網址 → 學生交卷即自動上傳（畫面顯示「✅ 紀錄已自動上傳」，同時保留複製/下載當備援）
- 試算表「作答紀錄」：一列一份卷（班級、座號、得分、秒數、完整 JSON）
- 試算表「逐題明細」：一列一題（題目ID、作答、O/X）→ 這就是「每個學生曾做過哪些題」的完整履歷
- 題庫「錯題分析」→「☁ 從試算表載入紀錄」：不用再叫學生複製貼上，直接抓回來分析；載入後題庫每題會標「⚑ 已考過」，並可勾「排除已做過」出新卷不重複

## 注意

- `token=math809` 是簡易通行碼，想換就改 Code.gs 第一行的 TOKEN，收卷網址跟著改
- 之後改過 Code.gs 要「部署 → 管理部署作業 → 編輯 → 版本選新版本 → 部署」網址才會更新內容
