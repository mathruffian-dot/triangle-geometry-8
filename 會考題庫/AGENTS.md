# AGENTS.md — 會考題庫（子目錄）

> **完整的入口文件在上一層：`../AGENTS.md`**，先讀那份。
> 這裡只放「在這個目錄工作」時最常需要的東西。

## 先做這兩件事
```bash
python scripts/config.py        # 確認設定（GAS 網址、Cloudflare 專案名、字型路徑）都對
python scripts/selftest_all.py  # 端到端自測；改完任何東西也跑這個，看到「✓ 全部通過」才算完成
```

## 現況與待辦
看 `handoff.md` 最上面的「⚡ 現況總覽」段（不要看更下面那些舊紀錄，那是時間序的歷史）。

## 這個目錄的規矩
1. **不要把網址、專案名、字型路徑寫死在腳本裡** → 加進 `scripts/config.py` 的 `DEFAULTS`，從那裡取。
2. **有進度就往 `handoff.md` 檔尾追加一段**（`### ✅ 日期 標題`），不要改別人寫的段落。
3. **改過模板卡就跑驗證**：`validate_templates_choice.py` / `validate_templates_essay.py`。
4. **新模板卡上線前要人工或另一個 AI 審題**——驗證器抓不到「多重正解」。
5. **產生 HTML/JS 後要 `node --check`**。
6. `redpen_out/`（學生手寫作答與姓名座號）、`data/config.json`、`命題模板/_草稿/`、
   `backup/*_備份_*.json` **都不進版控，也不要外流**。

## 地雷速查
- 微軟正黑體缺字：`⁴~⁹` 上標、`≈`、`∼`、`⅔`、`−`、`✓`、`✗`、`≤`、`≥`、`⇒` → 會變 □ 方框
- `0` 是合法級分，別用 `0 || ''` 或 `0 or ""`
- 班級／座號要去前導零再比對（Sheets 會把 `"09"` 變成 9）
- 一班一網址時卷名帶「｜<班級>班」後綴，批改指令要用完整名稱、一個班跑一次
- 完整清單見 `../AGENTS.md` 第 5 節與 Obsidian `04 踩坑總表`
