## 概念說明（學生會看到的文字）

數線與負數

數線上 0 的右邊是正數、左邊是負數；越往右越大、越往左越小。所以 −5＜−2＜0＜3。

絕對值 |x|＝這個數到 0 的距離。距離沒有負的，所以絕對值一定 ≥ 0：

|−4|＝4　　|4|＝4　　|0|＝0數線上兩點的距離＝大的減小的：−2 和 3 的距離＝3−(−2)＝5。

⚠ 兩個最常見的錯誤：
① 比大小：負數是「離 0 越近越大」，−1.5＞−2。
② |x|＝4 的答案有兩個：4 和 −4（距離 0 為 4 的點左右各一個）。

## 題目（基礎 3 題＋進階 3 題）

### 第 1 題（基礎）
下列哪一個數最小？
(A) −2　(B) −5 ✓　(C) 0　(D) 3
詳解:數線上越左邊越小：−5 在最左邊，最小。｜誘答/提醒:負數「負得越多」越小：−5＜−2。

### 第 2 題（基礎）
|−7| 等於多少？
(A) 14　(B) −7　(C) 0　(D) 7 ✓
詳解:|−7|＝−7 到 0 的距離＝7。｜誘答/提醒:絕對值是「距離」，一定不是負的。

### 第 3 題（基礎）
數線上 −2 和 3 兩點之間的距離是多少？
(A) 5 ✓　(B) 1　(C) −5　(D) 6
詳解:距離＝3−(−2)＝3＋2＝5。｜誘答/提醒:跨過 0 的距離要「兩邊加起來」：左邊 2 格＋右邊 3 格＝5 格。

### 第 4 題（進階）
下列哪一個數的絕對值最大？
(A) 6　(B) 7　(C) −8 ✓　(D) −3
詳解:|−8|＝8、|7|＝7、|6|＝6、|−3|＝3，最大的是 |−8|＝8。｜誘答/提醒:絕對值比的是「離 0 的距離」，不是數的大小——−8 雖然最小，距離卻最遠。

### 第 5 題（進階）
−1.5 和 −2 哪個比較大？
(A) −1.5 比較大 ✓　(B) −2 比較大　(C) 一樣大　(D) 無法比較
詳解:數線上 −1.5 在 −2 的右邊，所以 −1.5＞−2。｜誘答/提醒:正數是 2＞1.5，但負數相反：離 0 近的比較大。

### 第 6 題（進階）
滿足 |x|＝4 的數有哪些？
(A) 只有 −4　(B) 只有 4　(C) 4 和 −4 ✓　(D) 4 和 0
詳解:距離 0 為 4 的點有兩個：右邊的 4 和左邊的 −4。｜誘答/提醒:絕對值方程式通常有兩個答案，別漏掉負的那個。
