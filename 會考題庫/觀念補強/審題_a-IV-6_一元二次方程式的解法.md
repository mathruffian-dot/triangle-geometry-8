## 概念說明（學生會看到的文字）

核心原理：A×B＝0，那 A＝0 或 B＝0

例：(x−2)(x＋3)＝0 → x−2＝0 或 x＋3＝0 → x＝2 或 x＝−3（兩個解都要寫！）

解題步驟：
① 整理成「＝0」的形式
② 因式分解（提公因式／平方差／十字交乘）
③ 每個因式各自＝0，解出兩個答案例：x²−4x＝0 → x(x−4)＝0 → x＝0 或 x＝4。

⚠ 兩個最常見的錯誤：
① x²−4x＝0 兩邊除以 x 會把 x＝0 這個解弄丟——用提公因式，別亂除。
② 解出來的符號跟因式相反：(x＋3)＝0 的解是 x＝−3。

## 題目（基礎 3 題＋進階 3 題）

### 第 1 題（基礎）
方程式 (x−2)(x＋3)＝0 的解是？
(A) 只有 x＝2　(B) x＝−2 或 x＝3　(C) x＝2 或 x＝3　(D) x＝2 或 x＝−3 ✓
詳解:x−2＝0 → x＝2；x＋3＝0 → x＝−3。｜誘答/提醒:解的符號和括號裡「相反」：(x＋3) 的解是 −3。

### 第 2 題（基礎）
方程式 x²−9＝0 的解是？
(A) x＝9 或 x＝−9　(B) 只有 x＝3　(C) 只有 x＝−3　(D) x＝3 或 x＝−3 ✓
詳解:(x＋3)(x−3)＝0 → x＝±3。｜誘答/提醒:二次方程式通常有「兩個」解，別漏掉負的。

### 第 3 題（基礎）
方程式 x²＝16 的解是？
(A) 只有 x＝4　(B) x＝4 或 x＝−4 ✓　(C) x＝8 或 x＝−8　(D) x＝256
詳解:x²−16＝0 → (x＋4)(x−4)＝0 → x＝±4。｜誘答/提醒:開平方要有正負兩個答案。

### 第 4 題（進階）
方程式 x²＋5x＋6＝0 的解是？
(A) x＝2 或 x＝3　(B) x＝−2 或 x＝−3 ✓　(C) x＝−1 或 x＝−6　(D) x＝5 或 x＝6
詳解:(x＋2)(x＋3)＝0 → x＝−2 或 x＝−3。驗算：(−2)²＋5×(−2)＋6＝0 ✓。｜誘答/提醒:括號是「＋」解就是「−」——最後把解代回去驗算。

### 第 5 題（進階）
方程式 x²−4x＝0 的解是？
(A) 只有 x＝0　(B) 只有 x＝4　(C) x＝2 或 x＝−2　(D) x＝0 或 x＝4 ✓
詳解:提公因式：x(x−4)＝0 → x＝0 或 x＝4。｜誘答/提醒:兩邊除以 x 會弄丟 x＝0 這個解——永遠用因式分解。

### 第 6 題（進階）
方程式 x²−2x−3＝0 的解是？
(A) x＝−3 或 x＝1　(B) x＝3 或 x＝−1 ✓　(C) x＝3 或 x＝1　(D) x＝−3 或 x＝−1
詳解:找兩數：相乘＝−3、相加＝−2 → −3 和 1：(x−3)(x＋1)＝0 → x＝3 或 −1。｜誘答/提醒:十字交乘的符號要驗算：−3×1＝−3 ✓、−3＋1＝−2 ✓。
