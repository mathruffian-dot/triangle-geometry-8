## 概念說明（學生會看到的文字）

頂點式一眼看出頂點

y＝a(x−h)²＋k　→　頂點 (h, k)、對稱軸 x＝h例：y＝(x−3)²＋2 → 頂點 (3, 2)；y＝(x＋1)²−4 → 括號是 (x−(−1))，頂點 (−1, −4)。

極值（最大或最小值）：

a＞0 開口向上 → 頂點最低 → 有最小值 k
a＜0 開口向下 → 頂點最高 → 有最大值 k（下圖最大值 2）⚠ 最常見的錯誤：h 的正負號看反——(x＋1)² 的 h 是 −1 不是 1（想成 x−(−1)）。

## 題目（基礎 3 題＋進階 3 題）

### 第 1 題（基礎）
y＝(x−3)²＋2 的頂點是？
(A) (3, −2)　(B) (−3, 2)　(C) (3, 2) ✓　(D) (2, 3)
詳解:對照頂點式 y＝a(x−h)²＋k：h＝3、k＝2 → 頂點 (3, 2)。｜誘答/提醒:括號裡是 (x−3)，h 就是 3（跟著減號後面的數）。

### 第 2 題（基礎）
y＝(x＋1)²−4 的頂點是？
(A) (1, −4)　(B) (−1, −4) ✓　(C) (−1, 4)　(D) (1, 4)
詳解:(x＋1)＝(x−(−1))，所以 h＝−1、k＝−4 → 頂點 (−1, −4)。｜誘答/提醒:括號裡是「＋1」時 h 是 −1——正負號要反過來想。

### 第 3 題（基礎）
y＝(x−2)²＋5 的對稱軸是？
(A) x＝2 ✓　(B) x＝−2　(C) x＝5　(D) y＝5
詳解:對稱軸通過頂點：x＝h＝2。｜誘答/提醒:對稱軸是「x＝…」的鉛垂線，不是 y＝…。

### 第 4 題（進階）
y＝(x−1)²＋3 有最大值還是最小值？值是多少？
(A) 最小值 3 ✓　(B) 最大值 3　(C) 最小值 1　(D) 最大值 1
詳解:a＝1＞0 開口向上，頂點 (1, 3) 是最低點 → 最小值 3。｜誘答/提醒:極值是頂點的「y 座標」k，不是 h。

### 第 5 題（進階）
y＝−(x−1)²＋2 的最大值是多少？
(A) 沒有最大值　(B) 1　(C) −2　(D) 2 ✓
詳解:a＝−1＜0 開口向下，頂點 (1, 2) 是最高點 → 最大值 2。｜誘答/提醒:開口向下才有「最大值」；最大值＝頂點的 y 座標。

### 第 6 題（進階）
y＝2(x＋3)²−1 有最大值還是最小值？值是多少？
(A) 最小值 −1 ✓　(B) 最大值 −1　(C) 最小值 −3　(D) 最大值 3
詳解:a＝2＞0 開口向上 → 有最小值＝k＝−1（頂點 (−3, −1)）。｜誘答/提醒:先看 a 的正負決定「最大或最小」，再讀 k 值。
