# 會考數學題庫系統 — 使用說明

## 一、兩個網址

| 網址 | 給誰 | 用途 |
|---|---|---|
| **https://math809-bank.netlify.app** | 老師專用（勿給學生，含全部詳解） | 題庫瀏覽、出卷、統計 |
| **https://math809-quiz.netlify.app** | 發給學生 | 線上作答（目前掛「最近5屆第1-10題」示範卷） |

離線備用：`會考題庫/index.html`（資料夾內開啟）或 `會考題庫單檔版.html`（單檔隨身帶）。

## 二、老師端：題庫怎麼用

**找題目**（上方篩選列，可疊加，各選單皆可**複選**）：
- 年度／屆數：可勾多個年度，或按「最近3屆／5屆／10屆」快選後再增減
- 冊別：B1–B6 任意複選（如 B1+B2+B3+B4）；章節清單會自動跟著縮小、也可跨冊複選
- 學習內容代碼、**學習表現代碼**（複合表現的題目：勾任一相關代碼都會納入）、難度、題型皆可複選；不勾＝不限
- 題號範圍：`1-10` 或 `3,5,7-9`（例：最近5屆＋1-10 → 恰好 50 題）

**看題目**（每張題目卡）：
- 標籤：年度題號、冊別章節、學習內容（綠）、學習表現（橘）、難度
- 💡 **逐步引導**：按一次多顯示一步（課堂帶討論用）
- 📖 **完整詳解**：答案＋解析＋⚠易錯提醒

**勾題**：逐題勾「選入試卷」，或用「☑ 全選符合條件的題目」一鍵全勾（也有「勾選本頁全部」「清除勾選」）

**出實體卷**：勾選題目 → 🖨「列印勾選題目」＝學生卷；「列印勾選（含詳解）」＝教師卷

**出線上卷**：勾選題目 → 🌐「匯出線上試卷」→ 輸入卷名 → 下載 HTML 檔 → 上架（見下方）

**命題分析統計** 頁籤：各冊別／章節／學習內容／學習表現（複合逐碼計入）的歷屆出題數。

**錯題分析** 頁籤（學生考完後用）：
1. 把學生交回的作答紀錄貼進文字框（每行一筆，可全班一起貼）→ 按「分析錯題」
2. 得到：學生摘要表、錯題排行（幾人錯、誰錯、答什麼）
3. 每個錯題可展開：
   - **(a) 學習表現精熟練習**：依該題的每個學習表現（含複合）各推 4 題、由易到難
   - **(b) 類題練習**：同學習內容/章節的相似題 6 題（相似度排序）
4. 勾選推薦題 → 「匯出補強卷」（線上）或「列印補強卷」（紙本），直接產生個人化補強

## 三、換學生卷（上架新的線上試卷）

1. 匯出的試卷檔改名為 `index.html`，放進 `會考題庫\netlify_deploy\` 覆蓋舊檔
2. 在 `會考題庫` 資料夾開終端機執行：
   ```
   netlify deploy --dir netlify_deploy --prod
   ```
3. 學生網址不變，內容換新卷（作答中勿部署）

題庫網站本身有更新時（如新增年度）：`python scripts/deploy_bank.py`

## 四、學生端：作答流程（iPad）

1. 開 https://math809-quiz.netlify.app
2. 填**班級、座號、姓名**（不填不能交卷）
3. 選擇題點 A/B/C/D；非選題把答案打進文字框（過程寫紙上）
4. 按「✅ 交卷」→ 選擇題自動批改、顯示得分與逐題○✕
5. 把「📋 作答紀錄」交回老師，三選一：
   - **複製紀錄** → 貼到 LINE／Classroom（最推薦）
   - **分享** → iPad 原生分享（AirDrop／訊息）
   - **下載紀錄檔** → JSON 檔案
6. 中途斷線、誤關頁面都不怕：作答自動暫存，重開會還原

## 五、試算表自動收卷（設定一次即可）

1. 依 `apps_script/試算表串接說明.md` 部署 Google Apps Script（約 5 分鐘，貼程式碼→部署→授權→拿到網址）
2. 題庫「錯題分析」頁最上方貼上收卷網址（含 ?token=math809）→ 儲存
3. 之後匯出的線上試卷都會自動內嵌：學生交卷 → 自動寫入試算表
   - 「作答紀錄」表：一列一份卷（班級、座號、得分、秒數、完整 JSON）
   - 「逐題明細」表：一列一題（題目ID、作答、O/X）＝每個學生的做題履歷
4. 錯題分析改用「☁ 從試算表載入紀錄」一鍵抓回（可用試卷名稱篩選），不必再請學生複製貼上
5. 載入後：題庫每題標「⚑ 已考過」、篩選列可勾「排除已做過」→ 出新卷、補強卷不重複
6. 學生端只需填班級＋座號（姓名選填）

## 五之一、作答紀錄（手動備援）

學生交回的是 base64 字串（或 JSON 檔），內容包含：
班級／座號／姓名、開始與交卷時間、作答秒數、得分，以及**逐題**的作答與對錯
（每題附題目 id 如 `115-01`，可直接對回題庫的課綱標記）。

之後要自動收卷：在試卷檔開頭 `CONFIG.submitUrl` 填入後端網址即可（交卷自動 POST，其他不用改）。
「客製化補強生成」預留此接口，之後再做。

## 六、注意事項

- 題庫網址是公開連結（僅無法被猜到），**只給老師**；學生只給 quiz 網址
- 線上卷答案有編碼混淆，但無後端下無法完全防拆——複習用 OK，正式評量等接後端
- 題目版權屬臺師大心測中心，僅供教學使用
