# 國中數學 九下（第 6 冊）全冊複習｜互動視覺化簡報

一頁一重點的簡報式複習網站，涵蓋 108 課綱國中數學九下（第 6 冊）全部三章，
每個重點都有**視覺化演示**與**範例**。規格比照第五冊（`../複習網站五`）。

## 線上網址（可發給學生）
**https://math809-review6.pages.dev**（Cloudflare Pages，主要）

## 開啟方式
直接用瀏覽器打開 `index.html`（需連網以載入 MathJax）。按「開始複習」進入；深連結：
- `index.html#present` → 直接進入簡報第一頁
- `index.html#p=20` → 直接跳到索引 20 的投影片（0 起算）

> ⚠️ 本機測試請用簡單伺服器：`python -m http.server 8886 --directory 複習網站六`。

## 操作
- **← →** 或**空白鍵**：上／下一頁；**Home / End**：最前／最後
- 左側**目錄**依章節跳頁；右上「☰ 目錄」在手機版可收合
- **24 頁有滑桿互動**：拋物線的 \(a\)／\(h\)／\(k\) 即時平移與開口變化、
  周長固定時面積隨邊長變化、四分位數逐步切分、盒狀圖逐步繪製、
  全距 vs 四分位距對極端值的反應、機率尺、樹狀圖逐層展開、
  骰子 36 格點數和、圖釘實驗次數與估計值收斂、
  空間中平行／垂直／歪斜切換、柱體展開圖攤平、體積逐層堆疊…
- 範例可按「顯示解答」自我檢測

## 授課教具（右側浮動工具列）
收合側欄、上／下一頁、**雷射筆（L，含淡出拖尾）**、**畫筆（P，5 色＋橡皮擦）**、
清除筆跡（C）、全螢幕。Esc 關閉雷射筆／畫筆；畫筆支援觸控螢幕。

**🔍 放大**：範例框與視覺欄右上角各有「放大」鈕，可把範例或圖解**放大成整頁**，
方便投影時用畫筆直接講解（HTML 內容會連同字級一起等比放大）；按「✕ 關閉」回到原頁。

## 一頁一螢幕
概念欄與視覺欄內容過高時會**自動等比縮小**，投影時整頁不需捲動。

### 課綱邊界（本冊刻意不放）
- **二次函數不做配方法、不做應用問題**——F-9-2 備註明訂兩者屬 **10 年級 F-10-1**，
  本章「聚焦在圖形的特性」。只處理已配方好的 \(y=a(x-h)^2+k\)。
- 不出現一元二次方程式的**判別式**（屬高中）。
- **樹狀圖以兩層為限**，且以對稱性（節點相同）的樹狀圖為主（D-9-2 備註）。
- **體積只做直角柱**——S-9-13 條文為「直角柱、直圓錐、正角錐的**展開圖**與**表面積**；
  **直角柱的體積**」，錐體體積公式不在條文內，本章錐體只做展開圖與表面積。
- 平均數／中位數／眾數屬 D-7-2（第 2 冊），本冊不重教，只在比較盒狀圖時引用。
- 相似形、圓、幾何證明、三心屬第 5 冊（九上），本冊不出現。

## 檔案結構
- `index.html`：頁面骨架（封面、目錄、舞台、控制列、教具）
- `style.css` / `svg.js` / `engine.js`：與第一～五冊共用同一份
- `ch1.js ~ ch3.js`：各章投影片資料與視覺化（可獨立增修）

要新增／修改某一頁，只要編輯對應 `chN.js` 內該投影片物件即可。
撰寫規格見 `../複習網站五/SLIDE_SPEC.md`。
