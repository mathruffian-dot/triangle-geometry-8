# 國中數學 九上（第 5 冊）全冊複習｜互動視覺化簡報

一頁一重點的簡報式複習網站，涵蓋 114 課綱國中數學九上（第 5 冊）全部三章，
每個重點都有**視覺化演示**與**範例**。規格比照二下版（`../複習網站`）。

## 開啟方式
直接用瀏覽器打開 `index.html` 即可（需連網以載入 MathJax 數學排版）。
按「開始複習」進入；也可用網址深連結：
- `index.html#present` → 直接進入簡報第一頁
- `index.html#p=20` → 直接跳到第 20 張投影片

> ⚠️ 用 `file://` 直接開，部分預覽環境會當成靜態快照而不執行 JS；
> 本機測試請用簡單伺服器：`python -m http.server 8891 --directory 複習網站五`，再開 `http://localhost:8891`。

## 操作
- **← →** 或 **空白鍵**：上一頁 / 下一頁；**Home / End**：最前 / 最後
- 左側**目錄**可依章節快速跳頁；右上「☰ 目錄」在手機版可收合
- 多數頁面有**滑桿 / 步驟滑桿**互動（比例線段、相似縮放、面積比、弦心距、
  點/直線/兩圓位置關係、圓心角與弧、弧長扇形、圓周角、直徑直角、
  外心 / 內心 / 重心逐步作圖…）
- 範例可按「顯示解答」自我檢測

## 授課教具（右側浮動工具列）
收合側欄、上/下一頁、**雷射筆（L）**、**畫筆（P，5 色＋橡皮擦）**、清除筆跡（C）、全螢幕。
Esc 關閉雷射筆／畫筆；畫筆支援觸控螢幕。

## 檔案結構
- `index.html`：頁面骨架（封面、目錄、舞台、控制列、教具）
- `style.css`：全部樣式（沿用二下版）
- `svg.js`：共用 SVG 幾何工具（角弧、刻度、坐標平面、公式卡 fbox、步驟器 stepper…）
- `engine.js`：投影片導覽與渲染引擎（沿用二下版）
- `ch1.js ~ ch3.js`：各章投影片資料與視覺化（可獨立增修）

要新增 / 修改某一頁，只要編輯對應的 `chN.js` 內該投影片物件即可。
