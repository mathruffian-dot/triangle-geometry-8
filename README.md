## 健檢與派卷

在 `會考題庫/` 執行：

```text
python scripts/config.py
python scripts/selftest_all.py --quick
```

快速自測包含全部題庫、評分規準、離線回歸測試、七支批改 CLI 啟動、模板與圖元件、試生成、網頁 JS。
不加 `--quick` 會另行重建題庫。模板的答案字母偏態仍會回報警告；通過自測不代表已完成數學獨立審題。

派卷順序：編輯 `data/quizzes.json` → 驗證 → `python scripts/build_quiz_site.py` → 老師確認 → Cloudflare 部署。
班級專屬卷名含「｜班級班」後綴，批改指令須使用完整卷名；上線後不可任意改名。
部署專案名稱取自 `scripts/config.py`，參考完整指令見 AGENTS.md。修改 GAS 程式仍由老師重新部署新版本。

## 回饋單與影片

- 回饋單會合併同卷、同班、同座號的最新選擇題紀錄；只有本卷非選齊全且全部覆核後才換算參考等級。
- 無選擇題、查詢失敗或未完成覆核時，顯示原因，不以零分代替缺資料。
- 影片本機路徑可放 `scripts/video_runtime.local.json`（範本 `video_runtime.example.json`），或使用 `MATH809_VIDEO_*` 環境變數。
- 從根目錄跑 `python scripts/generator.py q1 --check`，只檢查本機路徑與快取。新底圖需原始 PPTX 與 PowerPoint；正式製片另需可用的 HyperFrames 和語音模型。
- 成品位置：影片 `output/math_videos/`；回饋單預設 `會考題庫/backup/`，含學生資料，不可公開。

## 4-1 平行互動視覺化簡報（根目錄 index.html）

聚焦「114 國中數學 2 下 4-1 平行」的原創互動 HTML 簡報。

**使用方式**：直接開啟 `index.html`；點選或拖拉左側教學重點卡到右側焦點區；
用「截線角度」「平行距離」「保持平行」控制圖形；左右方向鍵切換重點。

**涵蓋重點**：什麼是平行線、截線切出八個角、同位角相等、內錯角相等、同側內角互補、
反過來判斷平行、求未知角、平行推理地圖。

> 公開版只使用單元教學概念與原創視覺化圖形，不上傳教科書 PDF 或頁面截圖。
