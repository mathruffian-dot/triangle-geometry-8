## 開啟方式
直接用瀏覽器打開 `index.html`（需連網以載入 MathJax）。按「開始複習」進入；深連結：
- `index.html#present` → 直接進入簡報第一頁
- `index.html#p=20` → 直接跳到索引 20 的投影片（0 起算）

> ⚠️ 本機測試請用簡單伺服器：`python -m http.server 8882 --directory 複習網站二`。

## 操作
- **← →** 或**空白鍵**：上／下一頁；**Home / End**：最前／最後
- 左側**目錄**依章節跳頁；右上「☰ 目錄」在手機版可收合
- **53 頁有滑桿互動**：代入／加減消去法逐步、坐標平面描點與象限、直線圖形隨係數變化、
  兩直線交點＝聯立解、比例分配、正比反比對照、數線上的不等式解區間、
  乘負數時不等號翻轉的演示、統計圖表切換、中位數排序動畫、中垂線性質、
  線對稱摺疊、三視圖立體堆疊…
- 範例可按「顯示解答」自我檢測

## 授課教具（右側浮動工具列）
收合側欄、上／下一頁、**雷射筆（L，含淡出拖尾）**、**畫筆（P，5 色＋橡皮擦）**、
清除筆跡（C）、全螢幕。Esc 關閉雷射筆／畫筆；畫筆支援觸控螢幕。

**🔍 放大**：範例框與視覺欄右上角各有「放大」鈕，可把範例或圖解**放大成整頁**，
方便投影時用畫筆直接講解；按「✕ 關閉」回到原頁。

### 課綱邊界（本冊刻意不放）
- 比例式**不教連比 a:b:c 與連比例式**（屬九上第 5 冊），不使用繁分數
- 統計代表值**不出「已知平均數反求某一筆資料」**（D-7-2 備註明文點名）；
  相對次數／累積次數／累積相對次數屬 D-8-1，在第 3 冊
- 不等式**只處理單一個**一元一次不等式，**不做雙不等號（1<x+2<5）與不等式聯立**
- 聯立方程式與其圖形**只處理相交於唯一交點**，不討論無解與無限多組解
- 幾何**不教「平行」與符號 ∥**（S-8-3，屬第 4 冊）、**不做尺規作圖流程**（S-8-12，屬第 4 冊）、
  不延伸到多邊形內角和
- 三視圖限 **3×3×3 且不中空**
- 全程**不出現「函數」一詞與 y=f(x)**（函數在第 4 冊）
