# 國中數學 七上（第 1 冊）全冊複習｜互動視覺化簡報

每個重點都有**視覺化演示**與**範例**。規格比照第五冊（`../複習網站五`）。

## 開啟方式
直接用瀏覽器打開 `index.html`（需連網以載入 MathJax）。按「開始複習」進入；深連結：
- `index.html#present` → 直接進入簡報第一頁
- `index.html#p=20` → 直接跳到索引 20 的投影片（0 起算）

> ⚠️ 本機測試請用簡單伺服器：`python -m http.server 8881 --directory 複習網站一`。

## 操作
- **← →** 或**空白鍵**：上／下一頁；**Home / End**：最前／最後
- 左側**目錄**依章節跳頁；右上「☰ 目錄」在手機版可收合
- **23 頁有滑桿互動**：數線上拖動看相反數與絕對值、加減法在數線上走路、
  負負得正的水位模型、10 的次方與小數點移動、質因數分解短除法逐步、
  短除法求 GCD／LCM 逐步、分數通分、指數律的展開對照、等量公理天平、移項法則逐步、
  應用問題的線段圖…
- 範例可按「顯示解答」自我檢測

## 授課教具（右側浮動工具列）
收合側欄、上／下一頁、**雷射筆（L，含淡出拖尾）**、**畫筆（P，5 色＋橡皮擦）**、
清除筆跡（C）、全螢幕。Esc 關閉雷射筆／畫筆；畫筆支援觸控螢幕。

**🔍 放大**：範例框與視覺欄右上角各有「放大」鈕，可把範例或圖解**放大成整頁**，
方便投影時用畫筆直接講解；按「✕ 關閉」回到原頁。

## 一頁一螢幕
概念欄與視覺欄內容過高時會**自動等比縮小**，投影時整頁不需捲動。

### 課綱邊界（本冊刻意不放）
- 絕對值**只**做意義與 \|a−b\| 表兩點距離，**不做**絕對值方程式與不等式（N-7-5 備註）
- 科學記號**不做**四則運算；負整數次方**僅限底數 10**（N-7-8 備註）
- 指數律**只**處理非負整數次方，且以**數字例**呈現（N-7-7 備註）
- 比與比例式、不等式、聯立方程式屬第 2 冊；一次函數、平行屬第 4 冊
